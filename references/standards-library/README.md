# PPE-BoK Standards Source Library — Controlled Intake

This directory is the controlled metadata index for standards/source files collected for PPE-BoK research and Standards Validation.

## Important access rule

The PPE-BoK repository is public. Full copyrighted standards PDFs are **not committed here** unless their redistribution rights have been independently verified as permitting public hosting.

Many standards are licensed documents that explicitly prohibit reproduction, networking, internet/intranet posting, or redistribution. For those documents, this directory records only controlled metadata, edition information, file identity and cryptographic hash values.

The actual source PDF may be held in an authorized private source repository, licensed standards platform, institutional subscription, or other access-controlled location.

## Relationship to the central Standards Register

This directory does **not** replace [`../Standards-Register.md`](../Standards-Register.md).

- `Standards-Register.md` is the active engineering standards index used by PPE-BoK.
- This directory records **source-file intake and acquisition state**.
- A file appearing in the intake manifest does not by itself prove that the edition is current, authoritative, legally redistributable, or sufficient to close a Standards Validation hold.

## Intake rules

For every received source file, record where possible:

1. issuing organization;
2. document identifier;
3. edition/year represented by the file;
4. document type and status if identifiable;
5. original uploaded filename;
6. SHA-256 hash;
7. redistribution/public-hosting disposition;
8. duplicate/alternate-copy relationships;
9. Standards Validation relevance;
10. current-edition verification status.

## Copyright and licensing

Do not commit a standards PDF to this public repository solely because a copy is available online or has been provided to the project. Public redistribution requires a separate rights determination.
