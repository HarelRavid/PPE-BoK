# PPE-BoK Historical Knowledge-Scope Recovery

**Status:** ACTIVE RECOVERY / ARCHITECTURE INPUT  
**Purpose:** Recover the maximum historical knowledge scope of the PPE-BoK before finalizing the new book architecture.  
**Rule:** The recovery is topic-driven, not chapter-count-driven. No historically intended engineering domain may be dropped merely because the new architecture uses fewer or differently numbered chapters.

---

## 1. Recovery principle

The historical PPE-BoK evolved through several architectures. The current redevelopment repository (Chapters 000–013) is therefore **not** treated as evidence that the intended book ended at Chapter 013.

The recovery process uses this hierarchy:

1. Recover historically explicit domains, topics, methods, materials, tests, design problems, joining methods, inspection methods, lifecycle activities and case-study areas.
2. Preserve the original depth intent where it is visible (for example, a topic planned as a dedicated scientific treatment must not be marked complete merely because it receives a short paragraph elsewhere).
3. Map each historical topic to the current book as one of:
   - **FULLY COVERED**
   - **PARTIALLY COVERED**
   - **ABSORBED / DUPLICATED**
   - **PLANNED BUT MISSING**
   - **NEEDS DEEPER TREATMENT**
   - **HISTORICAL INTENT NOT YET VERIFIED**
4. Only after the topic map is complete should a final chapter count and final TOC be fixed.

---

## 2. Original project objective recovered

The early master-course framework defined the project as a world-class engineering course, reference book and podcast covering the full plastic-piping field, including:

- plastic-piping fundamentals;
- materials science;
- international standards;
- engineering design;
- joining and welding technologies;
- equipment and process systems;
- quality, inspection and qualification;
- failure analysis;
- industrial case studies;
- future technologies.

This ten-domain framework is a **scope floor**. A final book architecture that omits any of these domains is incomplete unless the domain is intentionally moved to another volume and that decision is recorded.

## 7. Rules for comparison against the current redevelopment

The current Chapters 000–013 must now be evaluated against this historical inventory at the **topic-depth** level.

Examples:

- If current Chapter 009 mentions crystallinity briefly, that does not automatically close the historical crystallinity scope that included lamellae, spherulites, morphology and effects on strength, diffusion and welding.
- If current Chapter 011 contains one paragraph on PVDF, that does not automatically replace the historical dedicated PVDF-family deep dive.
- If current Chapter 012 explains MRS and SDR, it may absorb some historical Chapters 63–64, but regression analysis, HDB cross-framework treatment or lifetime prediction may still need deeper treatment.
- If current Chapter 013 discusses PE joining, that does not automatically close the full joining-technology domain across PE, PP, PVDF, solvent systems, high-purity fusion and specialized welding.

The closure question is always:

> **Does the current book preserve the intended engineering knowledge and depth, not merely the keyword?**
