**Scope:** reviewed Chapters 000–013  
**Purpose:** control figures, tables, checklists and equation-related reference assets across the book  
**Status:** INITIAL REGISTER — production artwork not yet locked

## 1. Asset control rule

Every engineering asset should have:

- one owner chapter;
- one engineering purpose;
- a stable working ID;
- a status;
- a statement of whether it is canonical, illustrative or chapter-specific;
- a final-lock check for numbering, captions and cross-references.

A placeholder is acceptable during technical development. It is not publication-ready artwork.

## 2. Status vocabulary

- **PLACEHOLDER** — engineering concept is defined; final artwork/table production remains open.
- **TEXT TABLE PRESENT** — manuscript table exists and still requires final editorial/visual treatment.
- **CHAPTER-SPECIFIC FINALIZATION OPEN** — technically defined but dependent on chapter review/standards lock.
- **FINAL** — publication-ready asset, after technical and editorial approval.

## 5. Asset integration findings

### ASSET-001 — Early chapters are technically asset-complete but visually incomplete

Most reviewed figures in Chapters 001–012 are conceptual placeholders. This is acceptable for the current content baseline but not for publication baseline.

### ASSET-002 — Table roles must remain explicit

Some tables are canonical engineering record models, while others are only orientation aids. Final captions should preserve that distinction so a reader cannot mistake a qualitative comparison for an allowable-design table.

### ASSET-003 — Numbering must remain working numbering until final TOC lock

Asset IDs should remain stable during integration, but all cross-references require a final pass after final chapter numbering / Part structure is frozen.

### ASSET-004 — Chapter 013 needs final reconciliation with this register

The Chapter 013 redevelopment package has its own asset-control history. Before final lock, compare the latest Chapter 013 manuscript against this register and confirm that all required assets listed by its gap-closure review exist in the integrated source.

## 6. Production sequence

1. preserve current engineering placeholders during integration;
2. close architecture and evidence registers;
3. complete standards/equation validation where required;
4. create final artwork from the approved engineering concept;
5. run technical review of the final figure/table itself;
6. run editorial/visual consistency pass;
7. mark asset **FINAL** only after both technical and publication review.
