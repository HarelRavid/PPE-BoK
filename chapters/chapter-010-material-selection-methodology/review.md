# Chapter 10 — Technical Review

## Status

**Full Draft — Technical review completed at chapter-methodology level; not yet Locked.**

## Scope review

- [x] Focuses on selection methodology rather than duplicating material-specific chapters.
- [x] Covers common industrial plastic piping systems.
- [x] Treats selection as a complete-system decision.
- [x] Avoids rare or experimental polymers.
- [x] Remains vendor-neutral.

## Engineering review

- [x] Begins with service definition rather than a preferred material.
- [x] Separates chemical compatibility from pressure-temperature capability.
- [x] distinguishes material classification, component rating, and system suitability.
- [x] Includes long-term strength, creep-related design logic, cycling, external loads, installation, joining, inspection, and repair.
- [x] Includes explicit re-evaluation triggers for system changes.
- [x] Does not claim that any single material family is universally superior.

## Evidence and uncertainty review

- [x] Chemical-resistance tables described as preliminary/screening information rather than universal approval.
- [x] Proprietary mixtures and uncertain simultaneous exposures identified as possible test cases.
- [x] Testing is not presented as proof beyond the tested conditions.
- [x] Engineering interpretations are separated from normative requirements.
- [ ] Add academic sources for combined chemical-mechanical ageing in later degradation chapters.

## Formula and units review

No design equation is introduced in this chapter. Equations for pressure design, temperature derating, cumulative exposure, permeation, and fatigue are intentionally deferred to dedicated technical chapters.

## Terminology review

- [x] Uses `piping system` for the complete system.
- [x] Uses `joining` and `fusion joint`, not metallic-welding terminology as a default.
- [x] Uses `chemical resistance` rather than implying universal chemical immunity.
- [x] PE100+, PE100-RC, and PE100 distinctions are stated cautiously.

## Duplication control

Detailed properties and selection ranges for individual materials are deferred to:

- Common PE piping materials;
- Common PP piping materials;
- PVC-U and PVC-C;
- PVDF and accessible fluoropolymer systems;
- ABS where industrially relevant;
- composite piping where included in final scope.

Detailed mechanisms are deferred to chapters on:

- creep and long-term pressure design;
- fatigue and pressure cycling;
- chemical ageing and environmental stress cracking;
- permeation and purity;
- abrasion and slurry transport;
- joining technologies;
- inspection and failure analysis.
