# Standards Index

תיקייה זו מיועדת לאינדקס תקנים, מפת תחולה והערות עבודה בלבד.

## אין להעלות לכאן

- עותקים מלאים של תקנים מוגנים בזכויות יוצרים.
- ספרים או מאמרים שאין הרשאה להפיצם.

## ניתן לשמור

- מספר התקן ושמו.
- מהדורה ושנת פרסום.
- סעיפים רלוונטיים.
- תקציר מקורי של הדרישות.
- הערות תחום תוקף.
- קישור רשמי לרכישה או לעמוד התקן.
- סטטוס: current, withdrawn, superseded או under review.
