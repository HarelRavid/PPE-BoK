## 1. Official ISO lifecycle / scope recheck

Official ISO public records were rechecked on 2026-08-16.

### ISO 16014-1:2019

- Edition 3, 2019;
- Published;

- Part 5 uses SEC-LS with absolute molecular-weight data.

### ISO 16014-2:2019

- universal-calibration method;
- Published / confirmed, stage 90.93;
- ISO public scope explicitly classifies the method as **relative** under ISO 16014-1.

### ISO 16014-3:2019

- low-temperature method;
- Published / confirmed, stage 90.93;
- organic eluent below 60 °C;
- polymer-standard calibration;
- relative method.

### ISO 16014-4:2019

- high-temperature method;
- Published / confirmed, stage 90.93;
- organic eluent from 60 °C to 220 °C;
- polymer-standard calibration;
- relative method.

### ISO 16014-5:2019

- SEC coupled with light-scattering detection;
- Published / confirmed, stage 90.93;
- molecular-weight data combined with concentration-sensitive detection;
- ISO classifies SEC-LS as an **absolute method** within its stated scope;
- stated applicability limits include compositionally varying block/graft/heterophasic copolymer cases.

## 2. Scientific / interpretation checks

### MG016-04-01 — SEC separation versus molar-mass assignment

PASS.

The candidate separates chromatographic size/exclusion behaviour from calibration/detector-based molar-mass assignment. It does not describe conventional SEC as a direct weighing method.

### MG016-04-02 — calibration provenance

PASS.

The candidate requires polymer-standard/universal/SEC-LS basis to remain attached to the reported result.

The IUPAC `apparent molar mass` framework supports the caution that SEC results calibrated using constitutionally different standard materials can require correction/qualification.

### MG016-04-03 — universal calibration

PASS.

The candidate does not call ISO 16014-2 absolute. It preserves the official classification as relative.

### MG016-04-04 — SEC-LS

PASS.

The manuscript uses `absolute` only in the ISO 16014-5 method-classification sense and immediately blocks the false inference `absolute = assumption-free`.

### MG016-04-05 — temperature routes

PASS.

The candidate uses the public ISO thresholds only as method-scope descriptors and does not prescribe a PE/PP laboratory recipe.

### MG016-04-06 — dissolution / representativeness

PASS as engineering interpretation.

The candidate treats dissolution, insoluble fraction, aggregation and degradation as sample-representativeness controls, not as invented ISO acceptance criteria.

### MG016-04-07 — topology

PASS.

The candidate states that topology can affect hydrodynamic behaviour but does not claim SEC alone establishes branch topology.
