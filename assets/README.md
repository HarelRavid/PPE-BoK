# PPE-BoK Engineering Assets

**PDS Version:** 1.0

This directory is the controlled home for engineering assets used across the book.

## Identifier convention

- Equation: `EQ-CCC-NNN`
- Figure: `FIG-CCC-NNN`
- Table: `TAB-CCC-NNN`
- Workflow: `WF-CCC-NNN`
- Worked Example: `EX-CCC-NNN`
- Decision Tree: `DT-CCC-NNN`
- Checklist: `CL-CCC-NNN`

`CCC` is the three-digit chapter number and `NNN` is the three-digit sequential asset number.

Examples: `EQ-013-001`, `FIG-013-002`, `TAB-013-001`.

IDs are never silently reused after a baselined asset is removed or superseded.
